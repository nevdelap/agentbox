# Coding standards

## Commit comments

- Limit the commit comment subject to 60 columns.
- Wrap every remaining commit comment line to 60 columns.

## Linter findings

- Fix linter errors, warnings, and suggestions in the source or configuration;
  do not suppress them merely to make a check pass.
- A suppression is allowed only for a documented, intentional exception
  authorized by the human that cannot be fixed without violating a required
  runtime or interface contract.
