Round 2 findings

IDSeverity and locationFinding and required correction
P13-2 High
implementation_plan.html:841–852, 875		 The required invocation isolates only AGENTBOX_DIR. The launcher still resolves policy and credential sources from $HOME, operation records from $XDG_STATE_HOME or $HOME/.local/state, and update state from $XDG_CACHE_HOME or $HOME/.cache. A grant-enabled run can therefore mount real ~/.config/gh/~/.ssh, and any run can inspect or write real user state. Require the harness invocation to set an isolated HOME, XDG_CONFIG_HOME, XDG_STATE_HOME, and XDG_CACHE_HOME under the fresh test root, create all fixture sources there, pin a test machine name, and use an explicit launcher context. Require refusal unless the supplied root is a fresh harness-owned directory.
P13-3 High
implementation_plan.html:876		 The cleanup contract requires an agentbox-task13-<run-id> label/prefix on containers and named volumes, but the current launcher creates those resources from the project path and emits only policy labels (see bin/ab:330–338, 2735–2745). The harness cannot add that label without a production interface that the task forbids adding, and renaming resources would break logical identity. Define cleanup using exact names/IDs recorded from this run plus a harness-owned label for harness-created networks, or explicitly add and scope a supported run-label input. In either case, cleanup must verify ownership before removal and never use a broad prefix scan.
P13-4 High
implementation_plan.html:868, 881–885		 P13-06 requires injecting removal, creation, required/optional-network, readiness, invalid-record, and cleanup failures, but the plan defines no deterministic injection mechanism or per-failure setup. Task 13 is a live-runtime harness, while Task 12 owns mocked failure coverage; a Luna implementer cannot produce repeatable evidence for Docker removal/creation or cleanup failures from the stated commands. Either define a safe, explicit fault-injection seam and the setup/expected record for each failure, or move non-runtime-injectable failures to Task 12 and limit Task 13 to failures reproducible through documented isolated runtime operations.
